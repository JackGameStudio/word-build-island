## 核心融合哲学

- **主界面是岛屿，背词是覆盖层**，不是平行 Tab
- **单向切换，轻量进出** — 背完词卡片收下去，资源飞回岛屿
- **分阶段解锁** — 初期纯背词，中期解锁建造，后期引入复杂经济
- **像素风统一视觉** — 消除两套 UI 的风格冲突

## 面板互斥机制

两个面板都从底部滑出，但不会冲突 — 互斥规则如下：

| | 背词覆盖层 | 建造底部抽屉 |
|---|---|---|
| **视觉占比** | 占屏幕 60%，上方岛屿加半透明遮罩 | 占屏幕 ≤50%，上方岛屿无遮罩 |
| **触发方式** | 仅点击底部 "📚背单词" 按钮 | 点击岛屿空地 / 点击底部 "🏗️建造" |
| **打开时岛屿** | ❌ 不可交互（遮罩拦截所有触摸） | ✅ 可拖拽/缩放/点击其他空地 |
| **打开时对方** | 建造按钮在遮罩下不可见 | 背词按钮在抽屉底下不可见 |
| **关闭方式** | 答完一组 / 点击关闭 | 点击取消 / 完成建造 / 手指下滑 |

## 第一阶段：最小闭环 (MVP)

### 1.1 主界面：岛屿视图 (默认)

```
┌─────────────────────────────┐
│ 🏝️ 你的岛屿          ⭐3  💰88  🪵42 │  ← 顶部资源栏
│ ─────────────────────────────│
│                             │
│        🌲  🏠              │
│     🏠     🌲    🪨       │  ← Canvas 岛屿区域
│        🪨    🌲            │     (可拖拽/缩放)
│                             │
│                             │
├─────────────────────────────┤
│       [📚 背单词]           │  ← 中央大按钮
│        (点击开始背词)       │     (醒目像素风)
└─────────────────────────────┘
```

**设计要点：**
- 顶部资源栏：固定显示 ⭐积分 / 💰金币 / 🪵木材（最常用3个）
- 岛屿占据 80% 屏幕，背词按钮是唯一进入学习的方式
- 点击背词 → 底部滑出半屏卡片（背后仍可见岛屿）
- 背完一组（可设5词/10词）→ 卡片滑出，资源粒子飞向岛屿

### 1.2 背词覆盖层 (Overlay)

```
┌─────────────────────────────┐
│  ░░░░░░░░ 下方的岛屿 ░░░░░░│  ← 半透明层(70% opaque)
│ ░░░░░░░░░░░░░░░░░░░░░░░░░░│     可见但模糊
│ ░░░░░░░░░░░░░░░░░░░░░░░░░░│
├─────────────────────────────┤
│  [单词]  🔊                  │
│  benevolent               │  ← 顶部：当前词
│  /bəˈnevələnt/          │
│ ─────────────────────────────│
│  A. 仁慈的  B. 邪恶的      │
│  C. 勇敢的  D. 懒惰的      │  ← 4选1答题区
│ ─────────────────────────────│
│  ⏳ 下次复习: Box 2 (3天后)   │
└─────────────────────────────┘
```

**设计要点：**
- 覆盖层占 60% 屏幕高度（不是全屏）
- 背景岛屿半透明 + 模糊效果，保持"游戏感"
- 答题卡圆角像素风格（2px 直角，边框 2px）
- 答题后立即显示结果：正确→绿色闪烁+"+5💰"；错误→红色抖动+显示正确答案
- 一组答完，资源图标从卡片位置飞向顶部资源栏

### 1.3 建造入口 (隐藏至解锁)

```
MVP 阶段：
- 背词按钮下方显示 "建造岛屿 (需要 50💰解锁)"
- 赚够 50💰 后，按钮变成 "🏗️ 开始建造"

进阶阶段（Phase 2+）：
- 岛屿上闲置的格子显示虚线框提示可建造
- 点击虚线框 → 弹出底部抽屉（不是侧边）
```

## 第二阶段：建造系统

### 2.1 建筑底部抽屉 (Bottom Drawer)

**为什么不用侧边：**
- 手机侧边面板：拇指够不到，误触率高
- 底部抽屉：拇指自然落点区域（屏幕下半部），操作舒适
- 与背词卡片的"底部滑出"行为一致，一套交互学一次

**触发场景：**
- 点击岛屿空地 → 该格子高亮 → 底部抽屉滑出
- 点击底部"🏗️建造"按钮 → 直接弹出抽屉

```
┌─────────────────────────────┐
│                             │
│        🏝️ 岛屿区域           │
│                             │
│       ┌─────────┐           │
│       │ ★空地  │ ← 高亮    │  ← 被点击的格子
│       └─────────┘           │
│                             │
├═════════════════════════════┤  ← 抽屉从底部滑出，最大高度 50%
│  ═══════════  ⬆️ 拖动关闭 ══│  ← 拖动条（拇指滑即关）
│  ─────────────────────────── │
│  🏗️ 选择建筑                │
│  ─────────────────────────── │
│  🏠 小屋    💰30   [建造]  │  ← 有足够资源，亮色可点
│  🏰 城堡    💰50   [建造]  │
│  ⛩️ 神社   💰100  [建造]   │
│  🗼 灯塔   💰200  [建造]   │
│  ─────────────────────────── │
│  ⛏️ 伐木场  💰80  🔒需30词│  ← 资源不足 → 灰显+显示解锁条件
│  🏪 商店   💰150  🔒需60词│
│  ─────────────────────────── │
│        [  取消  ]           │  ← 底部固定，拇指一勾关闭
└─────────────────────────────┘
```

**抽屉内操作规则：**
| 状态 | 显示 | 交互 |
|------|------|------|
| 资源充足 | 亮色，正常价格 | 点击 → 选中建筑 |
| 资源不足 | 灰显 + 提示文字 | 点击 → 轻抖动 + 提示"再背 N 个词解锁" |
| 未解锁 | 🔒图标 + 解锁条件 | 完全不可点击 |

### 2.2 建筑放置完整流程

**共四步，全程单手完成：**

```
第1步：点击空地
┌─────────────────────────────┐
│                             │
│       ┌─────────┐           │
│       │ ★空地  │ ← 脉冲高亮 │  ← 点击岛屿任意空地
│       └─────────┘           │
│                             │
│  ┌────────── 底部抽屉滑出   │  ← 抽屉上滑
└──┴──────────────────────────┘

第2步：选择建筑
┌─────────────────────────────┐
│  ═══════════  ⬆️            │
│  ─────────────────────────── │
│  🏗️ 选择建筑                │
│  ─────────────────────────── │
│  🏠 小屋    💰30   [建造]  │  ← 点击"建造"按钮
│  🏰 城堡    💰50   [建造]  │    ↓
│  ⛩️ 神社   💰100  [建造]   │
│  ─────────────────────────── │
│        [  取消  ]           │
└─────────────────────────────┘

第3步：幽灵预览
┌─────────────────────────────┐
│  底部抽屉收起               │
│                             │
│    ┌─────────┐             │
│    │  🏠     │ ← 建筑跟随 │  ← 手指在岛屿上滑动时
│    │ (50%α)  │   手指移动  │    建筑预览跟随
│    └─────────┘             │
│                             │
│  [✔ 确认]   [✕ 取消]       │  ← 底部固定按钮
└─────────────────────────────┘

第4步：确认放置
┌─────────────────────────────┐
│  💰 -30 弹出动画            │
│    └→ 飞向资源栏            │
│                             │
│  🏠 建造完成！              │  ← Toast 弹出，2秒后消失
│  租金收入 +10% 持续 24h     │
└─────────────────────────────┘
```

**关键细节：**
- 抽屉内点击"建造"→ 抽屉自动收起 → 进入幽灵预览模式，不打断流程
- 幽灵预览阶段，手指在岛屿上拖动，建筑 sprite 跟随移动（50% 透明度）
- 岛屿之外拖动 → 幽灵消失，需要重新点击空地
- 确认键点击 → 扣除资源 + 播放建造动画 + Toast 通知 + 格子锁定
- 取消键点击 → 直接退出预览模式
- 放置完毕自动回到岛屿视图

```
/src
  /core
    /island-engine    ← FunIsland-V3 提取，Canvas 渲染
    /vocab-engine   ← LearningIsFun 提取，Leitner 逻辑
    /economy       ← 资源管理，Buff 计算

  /components
    /ResourceBar    ← 顶部资源栏
    /VocabCard      ← 背词覆盖层
    /BuildDrawer    ← 底部抽屉（关键新组件）
    /BuildPreview   ← 幽灵预览层
    /Toast          ← Buff 通知
  /styles
    /pixel.css      ← 像素风格 UI token
  App.svelte        ← 主入口，按 Phase 控制显示
```

**提案已确认**：Svelte 改为 **Vite + Vanilla JS 模块化**。不绑框架，保持简单，同时获得编译检查和 import 安全。

## 技术架构（v1.1 更新）

```
/word-island-builder
  /src
    /core
      /island-engine.js   ← 岛屿Canvas渲染（俯视，12×12网格）
      /vocab-engine.js    ← LearningIsFun 复用（SM-2 + Leitner）
      /economy.js         ← 资源管理 + Buff计算 + 离线收入
      /storage.js         ← IndexedDB 封装
    /components
      /ResourceBar.js     ← 顶部资源栏
      /VocabOverlay.js    ← 背词覆盖层
      /BuildDrawer.js     ← 底部抽屉（关键新组件）
      /BuildPreview.js    ← 幽灵预览层
      /Toast.js           ← Buff 通知
    /styles
      /pixel.css          ← 像素风格 UI token
    /main.js              ← 入口
  /index.html
  /package.json
  /vite.config.js
```

**组件规范**：
- 每个组件 `export default function render(ctx)` 返回 DOM 元素
- 不做 Virtual DOM，直接操作 DOM
- import/export 由 Vite 编译检查，避免全局变量污染

## 附录 B：全局面板互斥状态机

```
AppState 枚举: IDLE | VOCAB | BUILD | PREVIEW

IDLE ──→ VOCAB   (点击 "📚背单词")
VOCAB ──→ IDLE  (答完 / 取消)
IDLE ──→ BUILD   (点击空地 / 点击 "🏗️建造")
BUILD ──→ PREVIEW (选中建筑 + 资源充足)
BUILD ──→ IDLE   (取消)
PREVIEW ──→ IDLE  (确认放置 / 取消)

禁止的转换（互斥保障）：
  VOCAB ─x─→ BUILD    (遮罩拦截触摸 → 不会触发)
  BUILD ─x─→ VOCAB    (背词按钮被抽屉覆盖 → 不可见)
```
