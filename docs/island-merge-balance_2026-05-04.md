# 🎯 Word Island Builder — 数值平衡详案

**基于现有数据**：
- LearningIsFun：84+词汇，Leitner 5盒，SM-2 算法
- FunIsland V3：16种建筑（5种未解锁），3种资源（gold/wood/stone），12×12地图

**设计约束**：
- 10岁孩子，每天10-15分钟
- ✨ 独立经济体系，不绑定 FunIsland V3 数值
- 词汇学习是资源主要来源，建筑收入起辅助作用
- 全新开始，不迁移旧数据

## 四、建筑产出（被动收入）

### 4.1 保留 V3 的 per-second 经济体系，但做以下调整：

**核心调整：在线 vs 离线**
```
在线模式（正在刷词/建造）：
  建筑产出 = 原始 V3 income × 1.0  (full speed)
  
离线模式（没打开游戏）：
  建筑产出 = V3 income × 0.1  (10% speed)
  最多累计 8 小时的离线收益
```

### 4.2 产出对照（在线 10 分钟会话）

| 建筑 | 在线10分钟产出 | 相当于复习几个词？ |
|-----|-------------|------------------|
| 🪓 Lumberjack ×1 | 600 wood | ≈120个Box1词！⚠️ |
| 🏠 Cottage ×1 | 600 gold | ≈120个Box1词！⚠️ |

**🚨 问题发现：V3 的 1-second tick 让建筑产出远超学习奖励！**

### 4.3 解决方案：建筑产出降频

```
修改：ECONOMY_TICK = 6000ms (6秒，原来1000ms)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
在线10分钟（=100 ticks @ 6s）：
  🪓 Lumberjack: 100 wood  (原来 600)
  🏠 Cottage:    100 gold  (原来 600)
  
对比学习10分钟（~20个词复习）：~88g + 49w
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
结论：学习收入(gold:88, wood:49) ≈ 建筑收入(gold:100, wood:100)
      — 基本平衡！ ✅
```

## 八、防崩溃检查

### 8.1 日活跃监控指标

```
每活跃玩家的日均:
  gold收入:  目标 80-120   |  >300 则建筑tick减半
  wood收入:  目标 40-60    |  >150 解锁新消耗出口
  stone收入: 目标 10-20   |  <5   提高Box4奖励
  ⭐收入:    目标 2-5     |  >10  新建更贵建筑
```

### 8.2 三个"危险信号"

1. **孩子不建建筑只刷词** → 资源堆积 → 提示解锁新建筑
2. **建筑产出远超学习** → tick从6s延长到10s
3. **高级建筑形同虚设** → 降低⭐门槛 50%
