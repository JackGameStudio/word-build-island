# Word Island Builder — 按钮改用 9-slice 缩放
**时间**: 2026-05-29 12:20 GMT+8

## 修改内容

### 问题
原按钮使用 `background-image: url(btn-normal.png) center / 100% 100%` 拉伸，不同尺寸按钮有明显变形。

### 解决
改用 CSS `border-image` 实现 9-slice 缩放：

### 修改的文件

#### `src/assets/style.css`
- `.btn-pixel` 从 `background-image`（拉伸）→ `border-image`（九宫格）
- 四态对应：
  - 默认 → `btn-green-9slice.png`
  - hover → `btn-green-hover-9slice.png`  
  - disabled → `btn-disable-9slice.png`
- 新增 `.btn-danger` → `btn-read-9slice.png`（红色/危险操作）

#### `src/main.js`
- Settings 按钮改用 `.btn-pixel` + 紧凑 inline 样式

#### `src/components/SettingsPanel.js`
- 重置按钮改为 `.btn-pixel btn-danger` → 红色 9-slice 按钮（之前是硬编码 `background: #8b2020`）

### 9-slice 参数
- 图片尺寸: 64×64
- `border-image-slice: 8 fill` — 四角 8px 固定，边缘/中心自适应拉伸
- `border-width: 8px`

### 效果
- 任意尺寸的按钮都保持四角像素不变，只有中间内容区拉伸
- `btn-normal.png` / `btn-hover.png` / `btn-disabled.png` 旧图保留在 assets，不再被引用
